# House rules

The skills in this studio hold **method** — how to run a brief, an interview, a concept, a
review. They hold **no facts about your company**. Those come from two places:

1. **This file** — the rules: voice, words, conventions, people, places.
2. **Your knowledge sources** (Part 2) — the facts: what you sell, who buys it, what you have
   published, every number and every customer result.

If a skill needs something that is in neither, it says so and asks. It never fills the gap
with something that sounds right.

## Part 2 — Where our facts live

**Owner:** [Knowledge base / content library owner] · **Last reviewed:** [date]

**The rule that matters most:** every statistic, customer result, analyst position and
company figure is **fetched from a source below at the moment of writing**, quoted in that
source's exact wording, and cited. Nothing numeric is ever written from memory or stored in a
skill. If no source returns it, the copy shows `[PROOF POINT NEEDED]`.

## How other skills use this file

- **Before writing:** read Part 1. Voice is an input from the first word, not a correction
  at the end.
- **Before stating any fact:** go to Part 2. Fetch, quote exactly, cite.
- **Before filing or routing:** read Part 3.
- **If a rule is missing:** say so in one line — *"House rules don't cover headline case; I've
  used sentence case. Add it to house-rules Part 1.4."* That line is how this file gets better.
- **If this file still has [square brackets]:** the studio works, but says which rules it
  could not apply.
